
The goal of this fork is to let [Super Mario 64 Coop Deluxe](https://github.com/coop-deluxe/sm64coopdx/) mods use online website in-game.

## Initial Goal (Not avalable yet)

Modders could be using this to let poeple access online services (Like Twitch interactive, Web browser inside the game, and more...) using HTTPS (GET and POST) and Webhooks

## Documentation

This will always be using the latest version of SM64COOPDX
